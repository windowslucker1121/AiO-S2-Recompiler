# Legal

## What this project is

An unofficial, non-commercial program that recompiles game code from a dump the player supplies, so the player can run a game they own
on a PC. It is not affiliated with, endorsed by or sponsored by Nintendo, The Pokémon Company, Creatures Inc., GAME FREAK inc. or any
other game publisher.

## What it does not contain

- No game code, game files, assets, firmware, encryption keys or copyrighted game data.
- No download of games, keys or firmware, and no link to them.
- No code to break or bypass copy protection. It reads dumps that are already decrypted.

The player supplies their own dump, made from a console and a game they own. Whether making such a dump is allowed depends on the law of
the player's country. Players are responsible for following it.

Builds the player makes from their dump (recompiled code, extracted files, shader caches) are for their own use. Do not share them.
